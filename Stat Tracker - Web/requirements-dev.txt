# LOCAL DEVELOPMENT ONLY — for running
#   pip install -r requirements-dev.txt
#   python main.py
# on your own desktop machine while working on the app. Installs
# everything so every code path (desktop OpenCV camera + the native
# mobile camera classes, for reference) is importable while testing.
#
# DELIBERATELY NOT named "requirements.txt": Flet's own docs confirm that
# if a file with that exact name exists in the project, `flet build`
# reads dependencies from it INSTEAD OF pyproject.toml, on every
# platform, ignoring the per-platform [tool.flet.<platform>] split
# entirely. That's what silently caused a built Windows app to be
# missing opencv-python even though pyproject.toml correctly declared it
# for [tool.flet.windows] — this file existing under the name
# "requirements.txt" was overriding it. pyproject.toml is now the only
# thing that governs what `flet build` actually installs — see it and
# BUILD_INSTRUCTIONS.md for the per-platform breakdown.
